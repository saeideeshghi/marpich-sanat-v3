# شروع و تکرار پیوستهٔ پترن هدر و فوتر

## علت مکث در نسخهٔ قبلی

در فایل‌های فعلی، `lightPause`، `entranceDelay` و تأخیر مسیرها از قبل صفر بودند. مشکل از نحوهٔ عبور نور می‌آمد:

- نوار نور از بیرون محدودهٔ کامل مسیرها شروع می‌شد و تا رسیدن به قسمت قابل‌دیدن طرح، حرکتی از نور دیده نمی‌شد.
- تابع Smooth قبلی در ابتدا و انتهای هر عبور سرعت را به صفر می‌رساند. حرکت آرام از فضای بیرون طرح، زمان نامرئی بودن نور را طولانی‌تر می‌کرد.
- در پایان هر عبور هم نور بیرون طرح می‌رفت و چرخهٔ بعدی دوباره از همان محدودهٔ نامرئی آغاز می‌شد.

## اصلاح انجام‌شده

نور اکنون یک نوار داخل گرادینت تکرارشوندهٔ SVG است. فاصلهٔ تکرار برابر اندازهٔ صحنه در محور نور است: عرض برای طرح افقی و ارتفاع برای طرح عمودی. نقطهٔ روشن از داخل طرح شروع می‌شود. هنگام رسیدن یک نوار به لبه، تکرار مجاور از سمت دیگر وارد می‌شود.

خاصیت `spreadMethod="repeat"` باعث می‌شود جابه‌جایی دقیقاً به اندازهٔ یک تکرار، همان رنگ‌بندی را ایجاد کند. بنابراین برگشت ساعت انیمیشن از پایان چرخه به آغاز، تصویر را نمی‌پراند. [مرجع SVG 2](https://w3c.github.io/svgwg/svg2-draft/pservers.html#LinearGradientElementSpreadMethodAttribute)

در حالت Linear سرعت ثابت است. در حالت Smooth جدید، سرعت در تمام چرخه بین ۰٫۶۵ و ۱٫۳۵ سرعت پایه تغییر می‌کند؛ سرعت ابتدا و انتها برابر و مثبت است. تابع ورود محو همچنان مستقل و نرم باقی مانده است.

موج از همان مسیرهای تأییدشده و انیمیشن بومی SVG استفاده می‌کند. نمونهٔ آخر موج دقیقاً برابر نمونهٔ اول است؛ تغییر نور، شکل موج، موقعیت، رنگ ثابت و شفافیت انتخاب‌شده را عوض نمی‌کند.

## وضوح ۳۵٪ و شروع واضح‌تر موج

وضوح کل پترن هدر در هر سه اندازه و فوتر در دسکتاپ و تبلت روی `opacity: 35` قرار گرفته است. پروفایل عمودی فوتر موبایل تا عرض ۶۳۹px مقدار `opacity: 20` دارد. این مقدار مربوط به پروفایل اندازه است؛ وضوح مستقل مسیرها و نقاط رنگ تغییر نکرده‌اند.

اندازه‌گیری نسخهٔ قبلی نشان داد موج از ابتدا حرکت می‌کرد و انتهای حلقه هم مکث نداشت، اما مدت واقعی حدود ۲۸٫۲ ثانیه بود و جابه‌جایی در ۲۵۰ میلی‌ثانیهٔ اول بسیار کم دیده می‌شد. مقدار `period` از ۲۴ به ۱۲ ثانیه تغییر کرد. با حفظ `speed: 0.85` و ضریب سرعت فعلی پروفایل و مسیر، چرخهٔ واقعی حدود ۱۴٫۱ ثانیه است. دامنه، شکل مسیرها، جهت، نور و موقعیت طرح حفظ شده‌اند.

موج با زمان‌بندی خطی بومی SVG و `repeatCount="indefinite"` اجرا می‌شود؛ ورود محو و تأخیر شروع فعال نیستند. تکرار حلقه فریم ثابت یا مکث جداگانه‌ای اضافه نمی‌کند. زمان موج هنگام خروج از دید متوقف و هنگام بازگشت از همان موقعیت ادامه پیدا می‌کند.

مدت واقعی هر چرخهٔ موج:

```text
period / (speed × profile.motionSpeed × line.speed)
```

برای حرکت آرام‌تر یا سریع‌تر، کنترل «مدت موج» را در کاستومایزر تغییر بده؛ مقدار کمتر حرکت را سریع‌تر می‌کند. صفر نگه داشتن Delayها به‌تنهایی سرعت حرکت را تغییر نمی‌دهد.

## اعمال نسخهٔ جدید روی پروژه

۱. فایل‌های ZIP را روی پوشهٔ پروژه جایگزین کن. پوشهٔ تصاویر موجود را حفظ کن.

۲. برای اجرای محلی:

```powershell
npm run check
npm run dev
```

۳. برای بررسی خروجی GitHub Pages:

```powershell
npm run build:pages
npm run preview:pages
```

دستور انتشار موجود پروژه نیز Build جدید را اجرا می‌کند:

```powershell
npm run publish:github
```

ساخت پروژه ضروری است؛ اصلاح پترن داخل JavaScript مشترک است و حذف سایهٔ داخلی گواهینامه در آماده‌سازی تصاویر خروجی انجام می‌شود.

## تنظیمات کاستومایزر

در پنل پترن، هدر و فوتر و سپس هر اندازهٔ دسکتاپ، تبلت و موبایل را جدا انتخاب کن. برای حرکت بدون مکث، این مقادیر را حفظ کن:

| کنترل                   | کلید                   | مقدار                |
| ----------------------- | ---------------------- | -------------------- |
| نوع ورود                | `entrance`             | `none`               |
| تأخیر ورود              | `entranceDelay`        | `0`                  |
| مکث نور                 | `lightPause`           | `0`                  |
| تأخیر هر مسیر SVG       | `delay`                | `0`                  |
| نوع حرکت                | `easing`               | `linear` یا `smooth` |
| سرعت کلی، اندازه و مسیر | `speed`، `motionSpeed` | بزرگ‌تر از صفر       |

تنظیم فعلی پروژه: وضوح ۲۰٪ برای فوتر عمودی موبایل و ۳۵٪ برای سایر پترن‌ها؛ مدت پایهٔ موج ۱۲ ثانیه و سرعت کلی ۰٫۸۵.

## مسیرهای عمودی فوتر موبایل

در `src/data/patterns/footer-pattern.json`، فقط `artworks.mobile` اصلاح شده است. خطوط از منحنی رفتِ طرح اصلی ساخته شده‌اند؛ لبهٔ برگشتی نوار و قلاب بالایی حذف شده و امتداد بالا و پایین با همان مماس تا خارج کادر ادامه پیدا می‌کند. بنابراین نقطهٔ پایان یا برگشت کوچک داخل فوتر دیده نمی‌شود.

خاصیت `strokeOnly: true` همین Artwork، رنگ ثابت و نور را به Stroke اعمال می‌کند و Fill را خاموش نگه می‌دارد. حداقل ضخامت پیکسلی موجود برای همهٔ خطوط برقرار است. این گزینه توسط مدل کاستومایزر اعتبارسنجی و هنگام ذخیره و Export حفظ می‌شود. Artworkهای دیگر همچنان نوار توپر قبلی را رسم می‌کنند. حرکت موج و نور با زمان‌بندی و حلقهٔ قبلی ادامه دارد.

هر دو حالت حرکت بعد از این اصلاح پیوسته‌اند. `lightPause` و `delay` هنوز قابل تنظیم‌اند و مقدار مثبت آن‌ها عمداً مکث اضافه می‌کند.

مدت واقعی هر چرخهٔ نور:

```text
(lightPeriod + lightPause) / (speed × profile.motionSpeed × line.speed)
```

توقف پترن خارج از دید یا در تب پنهان، مصرف پردازنده را کم می‌کند. هنگام بازگشت، همان فاز ادامه پیدا می‌کند. تنظیم کاهش حرکت سیستم نیز همچنان رعایت می‌شود.

## گواهینامه‌های صفحهٔ درباره ما

مرز تک‌ستونه شدن بخش و کارت‌ها اکنون ۱۰۰۰px است. بالاتر از این مرز، متن بخش در راست و دو کارت عمودی کنار هم در چپ قرار دارند. تا این مرز، متن بخش بالا و کارت‌ها زیر آن هستند؛ داخل هر کارت، عکس راست و متن چپ است. عنوان، زیرعنوان انگلیسی و توضیح فارسی هر دو گواهینامه در همهٔ اندازه‌ها وسط‌چین‌اند. توضیح فارسی گالری و گواهینامه‌ها در موبایل همچنان ۱۲px است. توضیح گواهینامه کامل نمایش داده می‌شود و محدودیت دو خط عمومی کارت‌های دیگر روی آن اعمال نمی‌شود.

دو SVG گواهینامهٔ موجود، کل قاب، سایه و متن خروجی Figma را هم در خود دارند. فایل `build/certificate-assets.js` هنگام آماده‌سازی خروجی فقط عکس اصلی سند را از این دو خروجی شناخته‌شده استخراج می‌کند. سایه و نوشتهٔ تکراری داخل تصویر نمایش داده نمی‌شوند. فایل‌های اصلی صاحب پروژه تغییری نمی‌کنند و تصاویر سفارشیِ ناشناخته نیز دست‌نخورده باقی می‌مانند. بررسی این رفتار در `scripts/check-certificate-assets.js` به دستور `npm run check` اضافه شده است.

## متن مسیر توسعه در About

توضیح زیر تیتر (`.about-story__text.site-prose`) و توضیح هر مرحلهٔ تاریخچه (`.about-timeline__body > p.site-prose`) در تمام عرض‌ها ۱۴px هستند. دو قانون اختصاصی About در `src/data/customizer/settings.json` ثبت شده‌اند و `src/css/template-overrides.css` از همان تنظیمات تولید می‌شود. تغییر اندازهٔ متن عمومی سایت یا بازنویسی دستی فایل تولیدشده لازم نیست.
